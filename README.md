> ขับเคลื่อนด้วยระบบสุดล้ำ สวยงาม คมชัด และทำงานเร็วระดับ Native

## 📥 วิธีดาวน์โหลดและติดตั้ง (Download & Install)

คุณสามารถดาวน์โหลดตัวโปรแกรมไปใช้งานได้ฟรี โดยไม่ต้องติดตั้งโปรแกรมเสริมใดๆ

1. **ดาวน์โหลดไฟล์โปรแกรม**: คลิกที่ไฟล์ [Minecraft Mod Translation Studio 1.2.0.exe](./Minecraft%20Mod%20Translation%20Studio%201.2.0.exe) ที่อยู่ในหน้านี้
2. **กด Download**: เมื่อคลิกเข้าไปที่ไฟล์แล้ว ให้กดปุ่ม **Download** (ไอคอนลูกศรชี้ลง หรือไอคอน Download raw file) เพื่อเริ่มดาวน์โหลดไฟล์
3. **เปิดใช้งาน**: เมื่อดาวน์โหลดเสร็จสิ้น สามารถดับเบิลคลิกเปิดไฟล์ .exe เพื่อใช้งานโปรแกรมได้ทันที!

## 🌟 ฟีเจอร์หลัก (Key Features)

- 📜 **ระบบจัดการ FTB Quests**: แปลงเควสต์เป็น Translation Keys อัตโนมัติ พร้อมสร้าง Base Pack ให้ทันที
- 📦 **ระบบจัดการ Resource Pack**: เรียงลำดับความสำคัญของ Resource Pack ทั้งระบบ Paxi และ Vanilla
- ⚡ **ทำงานรวดเร็วแบบ Native**: ขับเคลื่อนด้วยเทคโนโลยีสมัยใหม่ ลื่นไหล ไม่มีสะดุด
- 🎨 **UI สุดล้ำ**: ดีไซน์แนว Steampunk Fantasy Studio ที่สวยงามน่าใช้
